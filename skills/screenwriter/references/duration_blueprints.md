# 时长蓝图 — Duration Blueprints

时长决定**信息容量、结构密度、场数与节拍数**。同一个故事,做成微电影和长片是两个物种。选错密度是新手最常见的失败。

> 估算惯例:中文剧本约 **1 页 ≈ 1 分钟**成片(动作密集会更快,对白密集会更慢)。

---

## micro 微电影(1-5 分钟)

| 项 | 参考值 |
|----|--------|
| 篇幅 | ~1-5 页 |
| 场数 | 3-8 场 |
| 结构 | **起承转合**,核心在"转" |
| 节拍 | 1 个核心事件 + 1 个关键转折 + 1 个"扣" |

- **铁律:做减法。** 单一人物线、单一事件、单一情绪。没有副线、没有群像。
- 开场 **10-20 秒内**必须抛出钩子(悬念/反常/危机)。
- 全片为最后那个**反转/顿悟/点题**服务——它就是微电影的价值本身。
- 结尾即点题,留白收束,余味比说尽更好。
- **典型失败**:塞进长片的信息量 → 节奏崩、收不住、什么都没讲透。
- 适配:剧情(一个瞬间的人性)、爱情(一次错过)、悬疑(一个反转)、喜剧(一个段子的升级)。

## short 短片(5-30 分钟)

| 项 | 参考值 |
|----|--------|
| 篇幅 | ~5-30 页 |
| 场数 | 8-30 场 |
| 结构 | **压缩三幕**(快建置、单冲突、强结尾) |
| 节拍 | 1 条主线 + 1 个核心冲突 + 2-3 个转折 |

- 一个主角、一个核心欲望、一个主要障碍。最多一条很轻的副线。
- 第一幕极短(1-2 场就要进入冲突);把篇幅留给"对抗"与结尾。
- 短片适合**一个尖锐的点子**(high-concept)或**一个浓缩的情感时刻**。
- **典型失败**:像"被砍短的长片",铺垫太长、高潮仓促。
- 适配:各类型皆可,尤其适合悬疑(一个谜)、剧情(一段关系)、科幻(一个设定实验)。

## feature 院线长片(90-120 分钟)

| 项 | 参考值 |
|----|--------|
| 篇幅 | ~90-120 页 |
| 场数 | 40-60 场 |
| 结构 | **完整三幕 + 中点 + 副线**;Save the Cat 15 拍;序列法 |
| 节拍 | 主线弧 + 1-2 条副线(B/C 故事)+ 6-8 个序列 |

- 主角有完整弧光;反派完整;B 故事(常为情感线)承载主题。
- 用**序列法**防止第二幕塌陷:把全片切成 6-8 个迷你电影,各有小高潮。
- 中点是结构脊梁:假胜/假败 + 信息反转 + 主角由被动转主动。
- **典型失败**:第二幕松散("中段塌陷")、副线与主题无关、节奏没有起伏。
- 适配:所有类型的"完全体"。详见 `story_structure.md` 的 15 拍。

## episode 剧集单集(40-50 分钟)

| 项 | 参考值 |
|----|--------|
| 篇幅 | ~40-50 页 |
| 场数 | 25-40 场 |
| 结构 | **单集闭环 + 季度大弧钩子**;A/B/C 多线;幕间钩子 |
| 节拍 | 本集 A 线闭合 + B/C 线推进 + 季度悬念前进一步 |

- **双层结构**:① 本集要有自己的小故事(开始-发展-本集高潮-小结);② 同时推进贯穿全季的大悬念/人物大弧。
- **A/B/C 故事线**:A=本集主线;B=人物关系线;C=轻松/喜剧或铺垫线。三线交织剪辑。
- **幕间钩子(Act-out)**:为适配广告位/集中注意力,每"幕"末尾(约每 10-12 分钟)留一个悬念钩子。
- **冷开场(Teaser)**:片头前用一个抓人的小段建立本集基调。
- 结尾留 **cliffhanger / 钩子**,逼观众看下一集。
- **典型失败**:本集不闭环(全是铺垫)、多线失衡(B/C 线喧宾夺主)、没有续看动力。
- 适配:剧情/悬疑犯罪/科幻最常见;单元剧(每集独立案件)vs 连续剧(强季度弧)需先定。

## 选择速查 & 自检
- 点子是"一个瞬间/一个反转"→ micro;"一个尖锐概念/一段浓缩情感"→ short;"一个完整人物旅程"→ feature;"一个能持续产出的世界与人物群"→ episode。
- **自检:我的节拍数量/场数与所选时长蓝图匹配吗?** 超了要砍,空了要补——而不是硬塞或注水。
