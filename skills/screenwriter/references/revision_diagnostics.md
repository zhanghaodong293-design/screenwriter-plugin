# 评析诊断 — Revision Diagnostics

`critique` 阶段用。给一份剧本/大纲/分场做体检,定位问题、按优先级开"修改单"。诊断的目的是**让作者更强**,不是炫耀挑刺——每条问题都要给可执行的修法。

---

## 诊断流程
1. **先复述故事**:用 1-2 句复述我读到的 logline 与主题。若复述不出 → 头号问题就是"故事核心不清"。
2. **七维体检**:逐项打分(✅达标 / ⚠️待改 / ❌硬伤)。
3. **定位而非泛评**:每个问题指到**具体场号/页**。
4. **开修改单**:按优先级(P0 硬伤 → P1 重要 → P2 打磨)排序,每条含"问题—为什么—怎么改"。
5. **先肯定亮点**:指出 2-3 个真正有效的地方,保住它们别在改写中改没了。

## 七维诊断清单

### 1. 结构(最优先)
- [ ] 有清晰的"主角欲望—阻力—转折—代价"链条?
- [ ] 激励事件够早、够有力?中心戏剧性问题立起来了吗?
- [ ] 第一幕转折(锁点)、中点、至暗时刻、高潮是否到位?
- [ ] 因果是"但是/因此"而非"然后"?有没有中段塌陷?

### 2. 人物
- [ ] 主角的 Want(外在)与 Need(内在)是否都明确、且会冲突?
- [ ] 主角有弧光(变/不变都要有设计)?开场显弱点、结尾有呼应?
- [ ] 反派/对抗力量是否够强、有自己的正当逻辑?
- [ ] 配角是否各有功能、无重复?

### 3. 对白
- [ ] 遮住人名认得出谁在说(个性化)?
- [ ] 有潜台词,还是 on-the-nose 复述情绪/剧情?
- [ ] 有没有信息倾倒(exposition dump)?
- [ ] 是否有该用"沉默/动作"代替的台词?

### 4. 场景
- [ ] 每场是否都有价值翻转/推进?有没有"原地踏步"的场?
- [ ] 是否晚进早出?有没有冗长的寒暄铺垫?
- [ ] 详略是否分明(高潮场浓、过渡场淡)?

### 5. 主题
- [ ] 主题是一个可辩论的命题,而非一个题目?
- [ ] 主题是被"演"出来的,还是被角色"说"出来的(说教)?
- [ ] 反派/对照人物是否体现了相反价值,形成论证?

### 6. 类型达标(对照 `genre_conventions.md`)
- [ ] 兑现了该类型的核心契约(悬疑给反转、爱情给情感、动作给刺激……)?
- [ ] 踩中该类型的"雷区"了吗?

### 7. 时长密度(对照 `duration_blueprints.md`)
- [ ] 节拍数/场数与所选时长蓝图匹配?(微电影别堆长片;长片别太单薄)
- [ ] 格式是否规范(对照 `screenplay_format_cn.md`)?

## 严重度分级
- **P0 硬伤**:动摇地基(无冲突/主角无目标/结构断裂/逻辑硬伤)。不修无法继续。
- **P1 重要**:明显削弱效果(反派薄弱/中段松/对白平/主题说教)。
- **P2 打磨**:锦上添花(个别台词、节奏微调、个别场删并)。

## 修改单格式
```
## 剧本诊断报告

**一句话复述**:[logline] / 主题:[一句话]
**总评**:[2-3 句:最大优点 + 最大问题]

**亮点(请保留)**
- …

**修改单(按优先级)**
| 优先级 | 位置 | 问题 | 为什么 | 怎么改 |
|--------|------|------|--------|--------|
| P0 | 第3场/中点 | 主角全程被动,没有"想要" | 故事没引擎,观众不知在等什么 | 在第2场给他一个具体外部目标:必须在天亮前… |
| P1 | … | … | … | … |

**下一步建议**:[先改结构还是先改人物;建议的重写顺序]
```

> 诊断语气:具体、对事不对人、每条可执行。先结构后细节——别在地基没稳时纠结台词。
