# 对白 — Dialogue

对白不是"人物在说话",是"人物在用话**做事**"——施压、试探、隐瞒、攻击、求和。台词见人品、见关系、见处境。

---

## 1. 对白的三个功能(一句好台词常同时干两件)
1. **推进剧情**:传递必要信息、做出决定。
2. **揭示人物**:身份、教养、情绪、价值观。
3. **制造/升级冲突**:有来有往的角力。
> 只交代信息、不带人物色彩的台词 = 报幕,要改写或拆成动作。

## 2. 潜台词(Subtext)—— 对白的灵魂

人物**很少直说真实意图**。台面在说 A,底下在要 B。

- on-the-nose(平):「我很生气你昨晚没回家,我觉得你不爱我了。」
- 有潜台词:(她把他那份早餐默默倒进垃圾桶)「……桌上有钱,自己叫外卖吧。」

制造潜台词的办法:答非所问、顾左右而言他、用客套包裹敌意、用玩笑掩饰受伤、谈天气其实谈感情。

## 3. 个性化 —— 一人一腔

把台词遮住名字,光看说法就知道是谁,才算成功。区分维度:
- **用词与句长**:文化程度、职业黑话、地域方言、年代感。
- **节奏**:急性子短句连珠;沉稳者长句、爱停顿。
- **口头禅/语病**:标志性的口头习惯(慎用,点到为止)。
- **说话策略**:有人直球,有人迂回,有人永远在反问。

## 4. 中式对白要点
- **口语化**:写完念出声,拗口、书面腔就改。中文对白忌"翻译腔"和成语堆砌。
- **身份感**:工人、教授、官员、孩子,遣词造句要对。参考《大佛普拉斯》底层人物的粗粝口语。
- **留白**:中文表达含蓄,"欲言又止""沉默""一个字都不说"往往比长篇更有力。
- **称谓**:称呼的变化(从"喂"到名字到昵称)能精准标记关系演变。

## 5. 常见毛病 → 修法
| 毛病 | 说明 | 修法 |
|------|------|------|
| 直白复述情绪 | 「我好难过」 | 改成动作/潜台词外化 |
| 信息倾倒(Exposition dump) | 一段台词塞满背景设定 | 拆散、藏进冲突、用画面交代 |
| 人人一个腔调 | 看不出谁在说 | 给每人定说话策略与用词 |
| 你问我答太顺 | 没张力 | 让人物答非所问、岔开、对抗 |
| 名字开头打招呼太多 | 「小李,你来啦」凑字 | 删,直接进入有信息量的话 |
| 旁白/画外音替剧情擦屁股 | 偷懒 | 优先用戏剧化场景;旁白只用于风格化表达(如《大佛普拉斯》导演画外音是**作者声音/反讽**,属设计而非偷懒) |

## 6. 节奏与排版
- 长短交替:对峙戏可用短句快打;抒情/独白用长句。
- 善用 **停顿、打断、重叠**:(沉默)、——(被打断)、省略号(欲言又止)都是表演提示。
- 一段台词别太长:超过 4-5 行就考虑用动作或对手的反应切开。

## 7. 沉默也是台词
最强的情感时刻常常无台词:一个眼神、一次转身、把话咽回去。**先问"这里能不能不说话?"** 能,就别写台词。

---

## 对白自检
1. 遮住人名,认得出谁在说吗?
2. 台面说的和心里要的,是不是同一件事?(最好不是)
3. 这句话同时在"推进 + 揭示/冲突"吗?
4. 念出声,顺口吗?像这个身份的人说的吗?
5. 这段能不能用动作代替?
