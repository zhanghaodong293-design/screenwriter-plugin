# 故事结构 — Story Structure

结构是剧本的骨架。先有骨,再长肉。本篇给四套可换用的结构模型 + 关键转折点。时长决定用哪一套的"密度",见 `duration_blueprints.md`。

---

## 一、三幕结构(地基,万能)

| 幕 | 占比 | 功能 | 关键节点 |
|----|------|------|---------|
| **第一幕 建置** | ~25% | 交代主角、日常、世界、欲望;打破平衡 | 开场画面 → **激励事件** → 第一幕转折点(主角被推上不归路) |
| **第二幕 对抗** | ~50% | 主角追求目标,障碍升级;**中点**翻转 | 一系列"尝试-失败"上升 → **中点**(假胜/假败,信息反转) → 危机/至暗时刻 |
| **第三幕 解决** | ~25% | 最终对决,回答中心问题;主角弧光完成 | 高潮(决战) → 结局(新平衡) → 收尾画面 |

### 六个不可省的转折点
1. **激励事件 / 触发事件**:打破日常的那件事(尸体出现、收到信、陌生人闯入)。
2. **第一幕转折(锁点)**:主角主动或被动地"上钩",从此回不去。中心戏剧性问题正式立起。
3. **中点(Midpoint)**:全片最重要的反转。假性胜利(其实危机更深)或假性失败(其实柳暗花明);常伴随信息揭露,改变游戏规则。主角从被动转主动。
4. **危机 / 至暗时刻(All Is Lost)**:主角失去一切,旧方法彻底失效,被迫直面内在课题(Need)。
5. **高潮(Climax)**:回答中心问题的最终对决;外部目标与内在转变在此合一。
6. **结局(Resolution)**:展示新平衡——主角/世界因这段经历变成了什么样。

## 二、Save the Cat 15 拍(长片精用)

Blake Snyder 的节拍表,适合 `feature`(页码按 110 页估):
1. 开场画面(p1) 2. 主题陈述(p5) 3. 铺垫(p1-10) 4. 推动/催化(p12) 5. 争论(p12-25) 6. **进入第二幕**(p25) 7. B 故事/副线(p30) 8. 玩乐时光(p30-55,兑现类型承诺) 9. **中点**(p55) 10. 坏人逼近(p55-75) 11. **一无所有**(p75) 12. 灵魂黑夜(p75-85) 13. **进入第三幕**(p85) 14. 结局(p85-110) 15. 终场画面(p110)。

> 用法:把它当**检查表**而非填空题。每一拍问"我的故事到这里发生了什么",缺了的补,生硬的改。

## 三、英雄之旅(神话/冒险/科幻奇幻好用)

精简 8 步:平凡世界 → 冒险召唤(+拒绝)→ 跨越门槛 → 试炼·盟友·敌人 → 接近最深洞穴 → 磨难(死亡与重生)→ 取得奖赏 → 携带万能药归来。
- 适合 `scifi`/`action`/`biopic` 的成长型主角。爱情/剧情可借其"门槛"与"磨难"。

---

## 四、起承转合(中式四段,微电影/短片尤佳)

| 段 | 功能 | 微电影占比 |
|----|------|-----------|
| **起** | 立人物、立情境、抛出"扣"(悬念/反常) | ~20% |
| **承** | 顺势发展,加压,信息累积 | ~40% |
| **转** | 一个意外/反转,扭转方向(全片支点) | ~25% |
| **合** | 收束,点题,余味 | ~15% |

中式短篇的灵魂在"**转**"——一个漂亮的反转或顿悟,常常就是整部微电影的价值所在。

---

## 五、序列法(把第二幕拆细,防"中段塌陷")

长片第二幕太长易松散。把全片切成 **6-8 个序列**,每个序列像一部 10-15 分钟的迷你电影:有自己的小目标、小高潮。第二幕 = 3-4 个序列接力,每个序列结尾把主角推入更深的麻烦。

---

## 选型速查
- 微电影 → 起承转合(强转折)。
- 短片 → 压缩三幕(一个核心冲突,快进快出)。
- 长片 → 三幕 + Save the Cat 15 拍 + 序列法;冒险/奇幻叠英雄之旅。
- 剧集单集 → 单集三幕(本集闭环)+ 季度大弧的钩子;A/B/C 线交织。
