# 人物 — Character

人物为王。观众记住的是人,不是情节。情节是"人物在压力下做选择"的产物。

---

## 1. 欲望(Want) vs 需求(Need) —— 人物的双引擎

| | Want(欲望) | Need(需求) |
|--|------------|------------|
| 性质 | 外在、具体、可见 | 内在、抽象、常被忽视 |
| 作用 | 驱动**情节** | 驱动**弧光/主题** |
| 例 | 赢得拳赛冠军 | 找回自尊、与父亲和解 |

- 主角通常**清楚自己的 Want,却看不清自己的 Need**。
- 好结局两种:① 放弃 Want、满足 Need(成长);② 得到 Want、却背叛 Need(悲剧/警世)。
- **冲突核心**:让 Want 与 Need 在高潮处不可兼得,逼主角选。

## 2. 目标-动机-障碍(GMC)

每个有戏的人物(尤其主角)都要能填:
- **目标(Goal)**:他想要什么(具体)。
- **动机(Motivation)**:为什么非要不可(越私人、越痛,越有力)。
- **障碍(Conflict)**:谁/什么挡着(外部障碍 + 自身弱点)。

## 3. 人物弧光(Arc)

主角从 A 状态走到 B 状态的内在轨迹。三种:
- **正向弧(成长)**:克服弱点,补上 Need(最常见)。
- **负向弧(堕落)**:被弱点吞没(《教父》麦克)。
- **平弧(坚守)**:主角不变,反而用信念改变了周围世界(很多英雄/类型片主角)。

写法:开场用一个**"显示弱点"的小事**埋下伏笔(救猫 / 踢猫时刻),结尾用一个**与开场呼应的选择**证明他变了/没变。

## 4. 反派 = 主角的镜像

弱反派 = 弱故事。强反派的要件:
- **有自己的正当性**:在他自己的逻辑里,他是对的。能说服一部分观众。
- **与主角共享处境、走了相反的路**:反派是"主角若做了另一种选择会变成的样子"。
- **施加的压力正好戳中主角的 Need**:反派是来"考主角内在课题"的考官。
- 力量上 ≥ 主角,才有压迫感(否则胜利廉价)。

## 5. 配角的功能(各司其职,不要重复)

| 原型 | 功能 |
|------|------|
| 导师 | 给主角工具/智慧,常在中段离场逼主角独立 |
| 盟友/搭档 | 陪伴、互补、提供对话出口,可制造人际冲突 |
| 爱人/情感线 | 承载 B 故事,常是 Need 的镜子 |
| 对照人物(Foil) | 与主角形成价值对比,凸显主题 |
| 门槛守卫/麻烦制造者 | 制造障碍、提速 |

> 检验:两个配角功能重叠?合并成一个更鲜明的。

## 6. 立体化技巧

- **矛盾点**:温柔的杀手、怕血的医生、虔诚的骗子——一个内在矛盾立刻让人物活起来。
- **靠选择揭示**,不靠描述:压力越大,选择越能暴露真我。给主角设"两难",看他选什么。
- **言行不一**:他说的、做的、想的可以有落差(潜台词的来源,见 `dialogue.md`)。
- **具体细节**:一个标志性动作/口头禅/物件,胜过一段身世简介。
- **关系网**:人物不是孤岛。先画"谁和谁什么关系、彼此想从对方要什么",戏自然就有了。

## 7. 类型与人物侧重(配合 `genre_conventions.md`)
- 剧情/爱情:重弧光与关系。
- 动作/科幻:可用平弧主角 + 强外部目标,但仍需一个内心软肋。
- 悬疑犯罪:主角的盲点 = 谜题的钥匙。
- 历史传记:在真实人物身上找一个"可戏剧化的内在冲突"作主线,不要平铺生平。

## 人物自检
1. 主角的 Want 和 Need 分别是什么?它们会在哪里冲突?
2. 反派在自己眼里"对"在哪?他凭什么压制主角?
3. 开场怎样显示弱点?结尾怎样呼应、证明变化?
4. 有没有功能重复的配角?
