# 中式电影剧本格式规范

成稿(`draft` 阶段)一律遵循本规范。中式剧本以**场**为单位,场头标注"场号、景别、时间、内外",正文用现在时、可视化的散文叙述动作,对白用"角色:台词"。

---

## 一、场头(场景标题行)

每场以场头开始,标准要素四件套:

```
场号、景别(地点),时间,内/外
```

- **场号**:连续编号(1、2、3……),便于制片拆分与统筹。
- **景别(地点)**:具体场景名,如"出租屋""老街茶馆""废弃工厂车间"。
- **时间**:日 / 夜 / 黄昏 / 拂晓(制片只需知道光线),必要时可写"日·雨"。
- **内 / 外**:室内或室外(影响布光与场地)。

**示例**
```
1、出租屋,夜,内
2、城中村巷口,日,外
3、医院走廊,黄昏,内
```

> 同一地点连续不同时间/内外,分立新场号。

## 二、动作叙述(场景描写)

场头之下,用散文写**镜头能拍到的一切**:环境、人物动作、关键道具、声音。

规范:
- **现在时、第三人称、可视化**。只写看得见、听得见的。
- **不写心理活动**。把"他很愧疚"改成可见行为。
- 人物**首次出场**时姓名可标注(年龄/身份),如"陈默(40 岁,沉默的修车工)";之后直接用名。
- 一段 3-5 行一断,保持呼吸感。重要音效可标注"(画外)汽笛声由远及近"。

## 三、对白

另起一行,**角色名:台词**。

```
陈默:钱我不要了,你走吧。
小雨:(没动)……外面在下雨。
```

- **括号提示**置于台词前或中,标注语气/动作:`(冷笑)` `(压低声音)` `(欲言又止)`。简短,只在必要时用。
- 旁白 / 画外音标注 **角色名(画外)** 或 **字幕**:
```
导演(画外音):各位观众朋友们大家好……
字幕:三年后
```

## 四、常用镜头/叙事手法标注

- **闪回**:`闪回:` 起,`闪回结束` 收。闪回须带新信息。
```
闪回:1998 年·老屋,日,内
   年幼的陈默躲在门后,看着父亲摔门而去。
闪回结束。
```
- **插入镜头**:`插入:报纸特写——头条"工厂大火三人遇难"。`
- **蒙太奇 / 段落**:用一组短句压缩时间。
```
蒙太奇——陈默的寻人之路:
   · 他在派出所翻档案。
   · 他在城中村挨家敲门。
   · 他在桥洞下,把寻人启事贴上墙。
```
- **转场**:需要强调时写 `(切)` `(叠化)` `(匹配剪辑接下一场)`;一般直切可不标。

## 五、完整片段范例(悬疑·短片)

```
1、修车铺,夜,内
   雨声。卷帘门半拉。陈默(40 岁,沉默的修车工)蹲在一辆轿车前,
   手电照着底盘。他伸手,从底盘缝里抠出一只沾血的女式发卡。
   他怔住。门外传来脚步声。
   陈默迅速把发卡塞进工装口袋,起身。
   来人是警察老周(50 岁)。

   老周:这么晚还不收?
   陈默:(背对他,擦手)马上。
   老周:(扫了一眼那辆车)……这车,谁的?
   陈默:(顿了一下)客人的。明早来取。

   老周盯着他看了两秒,笑了笑,转身走进雨里。
   陈默的手,在口袋里攥紧了那只发卡。

2、城中村巷口,日,外
   ……
```

## 六、反例(常见错误)→ 修正

| 反例 | 错在哪 | 修正 |
|------|--------|------|
| `陈默感到一阵恐惧和愧疚。` | 写了拍不到的心理 | `陈默的手抖了一下,发卡差点掉地。` |
| 场头写成"修车铺"无时间/内外 | 制片无法拆分 | `1、修车铺,夜,内` |
| 对白`陈默:我现在要去找凶手为我女儿报仇。` | on-the-nose 复述动机 | `陈默:(扣上工具箱)铺子关几天。`(动作暗示) |
| 动作叙述一大段不分行 | 难读 | 3-5 行一断 |
| 用画外音交代"其实他早就认出了凶手" | 偷懒 | 用画面/眼神/动作戏剧化呈现 |

---

## 排版小结
1. 场头:`场号、景别,时间,内/外`,连续编号。
2. 动作:现在时、可视化、不写心理、勤分段。
3. 对白:`角色:台词`,括号提示从简。
4. 手法:闪回/插入/蒙太奇/字幕/画外音 按上文标注。
5. 一切服务"可拍摄、可阅读"。
