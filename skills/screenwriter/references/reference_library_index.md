## 用法建议
1. 写某类型大纲前,挑 1 部同类型代表作,**只分析其结构/节拍**(画出它的三幕与转折点)。
2. 学对白,精读《低俗小说》《唐人街》《黑暗骑士》的对峙戏。
3. 学切口,看《奥本海默》《萨利机长》如何不平铺生平。
4. 需要库中更多同题材作品时,`ls` 库根目录并按片名筛选(库内还有大量中外电影剧本)。
