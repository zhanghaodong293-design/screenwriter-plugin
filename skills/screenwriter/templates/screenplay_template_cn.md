# 模板:中式剧本成稿

`draft` 阶段产出。逐场写。严格遵循 `screenplay_format_cn.md`。

```
片名:《XXX》
类型 / 时长:[genre] · [duration]
编剧:

———————————————————————

1、景别(地点),时间(日/夜),内/外
   动作叙述:现在时、可视化、只写拍得到的。首次出场标注人物
   (年龄/身份)。3-5 行一断。

   角色甲:台词。
   角色乙:(括号提示从简)台词。

   (需要时)闪回 / 插入 / 蒙太奇 / 字幕 / 角色(画外音) 按规范标注。

2、景别,时间,内外
   ……

———————————————————————
（结尾建议给一个有余味、与开场呼应的收尾画面）
```

成稿自检(逐场):
- 场头四要素齐全(场号、景别、时间、内外)?
- 动作只写"看得见"的?没写心理活动?
- 每场有价值翻转?晚进早出?
- 对白有潜台词、个性化、不复述剧情?
- 详略分明,高潮浓、过渡淡?

> 写完整稿后,转 `critique` 用 `revision_diagnostics.md` 做体检。
