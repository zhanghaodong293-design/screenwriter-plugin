# 模板:节拍表 Beat Sheet

`outline` 阶段产出。先选时长变体,再填节拍。每个节拍写"发生了什么 + 价值如何变化"。配合 `story_structure.md` 与 `duration_blueprints.md`。

## 通用头
```
## 故事梗概(一段式)
[150-300 字,把故事从头讲到尾,含结局,不卖关子]

## 节拍表（[duration] · [genre]）
```

---

## 变体 A:micro 微电影(起承转合)
```
起(立人物+抛扣):
承(加压+累积):
转(意外反转,全片支点):
合(收束点题,余味):
```

## 变体 B:short 短片(压缩三幕)
```
1 开场钩子:
2 激励事件(尽早):
3 第一幕转折(主角上钩):
4 对抗·尝试1(失败/加码):
5 中点(反转/新信息):
6 至暗时刻:
7 高潮(对决,回答中心问题):
8 结局(新平衡,呼应开场):
```

## 变体 C:feature 院线长片(Save the Cat 15 拍,可增删)
```
1 开场画面 / 2 主题陈述 / 3 铺垫 / 4 催化(激励事件) / 5 争论
6 进入第二幕 / 7 B故事(副线) / 8 玩乐时光(兑现类型) / 9 中点
10 坏人逼近 / 11 一无所有 / 12 灵魂黑夜 / 13 进入第三幕
14 结局(高潮→收束) / 15 终场画面
※ 标注 6-8 个序列,各自小目标与小高潮。
```

## 变体 D:episode 剧集单集
```
冷开场(Teaser):
A 线(本集主线):激励 → 发展 → 本集高潮 → 小结(本集闭环)
B 线(关系线):推进点 …
C 线(轻松/铺垫线):推进点 …
幕间钩子(每幕末,约 3-4 个):
季度大弧推进(本集向总悬念前进一步):
集尾钩子 / Cliffhanger:
```

> 填完自检:节拍数与所选时长匹配吗?每拍的"价值变化"写出来了吗?因果是"但是/因此"吗?
