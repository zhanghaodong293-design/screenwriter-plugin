# 模板:人物小传

`character` 阶段产出。主角写满,对手次之,配角从简。重点不是档案,是**能产生戏的信息**。

## 主角
```
姓名 / 年龄 / 身份:
一句话画像(带矛盾点):  例)温柔的退伍狙击手,怕看见血。
欲望 Want(外在目标):
需求 Need(内在课题,常自己不知):
动机(为什么非要不可,越私人越好):
弱点 / 致命缺陷:
弧光(起点状态 → 终点状态;正向/负向/平弧):
显示弱点的开场小事:
证明变化的结尾呼应:
标志性细节(动作/口头禅/物件):
```

## 对手 / 反派
```
姓名 / 身份:
他的"正当性"(在自己逻辑里为何是对的):
与主角的镜像关系(走了相反的路):
施加的压力如何戳中主角的 Need:
力量为何 ≥ 主角:
```

## 配角(每个一行,标功能)
```
[姓名] — 功能(导师/盟友/爱人/对照/麻烦制造者)— 想从主角要什么
```

## 人物关系网
```
用"谁 ↔ 谁:什么关系 + 彼此想要什么 + 张力点"列出核心关系。
例)陈默 ↔ 小雨:父女(疏离)|父想赎罪,女想真相|发卡是雷管。
```
