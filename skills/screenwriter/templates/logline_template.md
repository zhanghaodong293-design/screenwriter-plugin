# 模板:Logline & 创意

`logline` 阶段产出。一句话讲清整个故事的引擎。

## Logline 公式
> 当【激励事件】,一个【带定语的主角】必须【追求的目标/欲望】,否则【失败的代价】;但【主要阻力/反派】。

**要素自检**:主角是谁(带反差定语)· 想要什么(具体可见)· 谁/什么挡着 · 不成功的代价 · 故事的"反常/钩子"在哪。

## 产出格式
```
## Logline
[一句话,25-50 字,套用上面公式]

## 主题(一句话命题)
[可辩论的命题,如"复仇只会带来更深的空洞"]

## 类型 / 时长
[genre] · [duration]

## 钩子(为什么吸引人)
[一句:这个故事最反常/最抓人的点]

## 三个升级方向(供选择)
1. 【提高赌注】把代价/对手加重 → …
2. 【反转身份】给主角/反派一个意外身份 → …
3. 【道德两难】让目标与价值观冲突 → …
```

## 示例(悬疑·短片)
- **Logline**:当一只沾血的发卡出现在待修车底盘,一个寡言的修车工必须在警察查到之前查清真相,否则将替凶手顶罪;而最大的嫌疑人,是他失踪多年的女儿。
- **主题**:有些真相,知道了就再也回不去。
- **三个升级**:① 把"顶罪"改成"24 小时内";② 发卡其实是他自己女儿的;③ 查清真相意味着要亲手送女儿入狱。
